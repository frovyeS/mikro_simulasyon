# Mikro Simülasyon (MVP)

Şartname doğrultusunda GitHub'a yüklenebilir, Vite + React tabanlı bir başlangıç MVP'si.

## İçerik
- Newton çekimi tabanlı 2D parçacık/çok cisim simülasyonu
- Play / pause / reset / tek adım ve hız kontrolü
- Parametre kontrolleri, hazır deneyler ve cisim ekleme/silme
- Canvas pan (sürükle), zoom (mouse wheel), grid ve izler
- Ölçüm/analiz panelleri
- LocalStorage deney kaydı, JSON import/export
- Responsive arayüz ve light/dark tema

> Bu, şartnamedeki tüm kapsamı tamamlayan ürün değil; ilk çalışan MVP/prototip. Çarpışma, gerçek grafik zaman serileri, erişilebilirlik testleri, bilimsel doğrulama, test suite ve backend paylaşım henüz kapsam dışıdır. Model eğitim/keşif amaçlı basitleştirilmiştir.

## Çalıştırma
Node.js 18+ önerilir.

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## GitHub
